# 40, 60, 80, 100s

**Equipment:** Markers for distances, football field or measured area
**Time Cap:** 15-20 minutes
**Scaling:** Reduce distances by 10-20 yards, increase rest to 90 seconds

**Workout:**
1. 40-yard sprints × 6 (1 minute rest between)
2. 60-yard sprints × 4 (1 minute rest between)  
3. 80-yard sprints × 2 (1 minute rest between)
4. 100-yard sprint × 1

**Notes:**
Progressive distance sprint ladder that builds speed endurance. Start each distance at goal line if using a football field. Focus on acceleration and maintaining top speed as distances increase.
